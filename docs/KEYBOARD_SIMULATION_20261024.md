# 2026-10-24 模型库键盘仿真

## 入口与改动

此前当前 Walk 卡片叫“站立 / 行走”，键盘面板只对已退出目录的 Fast / Navigation ID 开启，用户看不到当前键盘模型，也不能在当前 Walk 仿真里操作。现第一项直接显示“键盘控制 · 当前实机模型”，沿用当前 Walk ONNX，不另造权重或重复卡片。

- 方向键与 WASD 使用实机已有的 `duck-keyboard.js`：前进 0.2 m/s、Shift 前进 0.3 m/s、后退 −0.3 m/s、左右转 ±1 rad/s；转向优先、反向抵消。画面显示可按住的方向键和 Shift，并高亮已按键。
- Space 运行/暂停，R 重置，Esc 清零行走指令；外层“仿真运行此模型”会把焦点交给仿真，随后可直接使用键盘。
- 松键、失焦、暂停、重置和离开模型页清零；恢复运行不重放旧按键。后台暂停也清零虚拟 twist。请求在途时只保留最新方向，避免旧指令排队。
- 相机跟随机身平移，保留用户旋转/缩放；底部功能键始终可见。其它三个模型仍可运行、暂停、重置和鼠标交互，只有 Walk 显示方向控制。

## 同日后续：首次空格与 Pick 嘴部

初版只在内层仿真文档接收键盘事件，焦点留在外层“模型”导航或模型卡片时，Space 无效；点运行后转移焦点才有效。现在外层工作台、模型库与仿真之间按当前模型及 SHA 传递 Space / R / Esc，首次 Space 即可启动，后续正常暂停/继续。输入框、组合输入、修饰键和按住重复不触发；在模型页不会把这些功能键发给实机。
